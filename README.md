# Zerus Homebrew tap

Homebrew cask for [Zerus](https://github.com/ufna/zerus), the ADE for working
with a fleet of AI coding agents across your machines.

```sh
brew install --cask ufna/zerus/zerus
```

The cask installs the signed and notarized `Zerus.app` and the `hgs` CLI on
Apple Silicon Macs. Native agents are installed separately.

The first cask is published with the next stable Zerus release. Casks in this
repository are generated and pushed by the Zerus release workflow from a verified
release candidate. Do not edit them by hand. Report problems in the
[main repository](https://github.com/ufna/zerus/issues).
